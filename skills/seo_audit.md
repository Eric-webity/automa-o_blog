# Skill: SEO Audit (marketingskills)

## On-page para cada matéria de blog
- **Title tag**: 50–60 caracteres, keyword no início, marca no fim se couber.
- **Meta description**: 150–160 caracteres, benefício + keyword + CTA suave.
- **H1**: único, editorial, keyword natural (sem stuffing).
- **H2/H3**: sub-intenções de busca; cada H2 responde uma pergunta.
- **Primeiras 100 palavras**: keyword principal e resposta à intenção.
- **Imagens**: sugerir alt text descritivo quando relevante.
- **Links internos**: sugerir âncoras para tópicos relacionados (placeholder).

## E-E-A-T no texto
- Demonstrar experiência com exemplos práticos.
- Precisão e detalhe; citar fontes das referências.
- Tom de especialista acessível.
- Secção "Fontes consultadas" com links.

## Profundidade
- Cobrir melhor que um artigo genérico: comparativos, prós/contras, limitações honestas.
